Unofficial beamer slide pack for University of Heidelberg, the project originated from a template found on [Overleaf](https://www.overleaf.com/latex/templates/harbin-institute-of-technology-hit-beamer-presentation-theme/prwxqwfdzkqj). Currently I am still in the process of fixing some of the graphical aspects, making some quality of life improvements and making sure that the template iteself is usable.
